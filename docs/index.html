Athan Clock

Plays the Athan at every prayer time for your city, automatically. Made for a home server, Raspberry Pi or any Linux machine that runs 24/7 and is connected to a speaker. Install it once with a single command, and it keeps running in the background, even after a restart.

Install View on GitHub

What it does

Athan at every prayer

Dhuhr, Asr, Maghrib and Isha, each with its own recording. Fajr can be turned on too.

Times for your city

Fetches accurate times every day from the Aladhan prayer times service, using the calculation method you choose.

Starts on its own

Runs quietly in the background and starts again after every reboot. A short chime tells you it's running.

Laptop friendly

If your computer was asleep through a prayer, that Athan is skipped rather than played late.

Install

Install it on a machine that stays on 24/7 and has a speaker connected. Works on Raspberry Pi OS, Debian, Ubuntu, Linux Mint and other Debian/Ubuntu-based Linux systems.

2

Copy the install command

Choose your location above and your settings will be built into the command. You can also copy it now and answer the questions in the terminal instead.

Only need the settings file? Download config.json and put it in the app folder (~/AthanClock), then run ~/AthanClock/RunAthan.sh restart.

3

Run it in a terminal

  1. Open Terminal (on Raspberry Pi: the black icon on the top bar, or press Ctrl+Alt+T).
  2. Paste the command (Ctrl+Shift+V) and press Enter.
  3. Type your password if it asks. It's needed once to install the sound player. Nothing is shown while you type, which is normal.
  4. When you hear a short chime, Athan Clock is running. That's it!

Don't add sudo in front of the command. The app runs under your own user so it can use your speakers. Everything is installed in ~/AthanClock. Running the same command again updates the app to the latest version.

Turn it off, on, or remove it

Open a terminal and run the command for what you want to do.

Pause it for now

Stops the Athan until the next restart.

~/AthanClock/RunAthan.sh stop

Turn it off completely

Stops it and keeps it from starting on boot. Your settings are kept.

~/AthanClock/RunAthan.sh stop && ~/AthanClock/RunAthan.sh disable-startup

Turn it back on

Starts it now and on every boot again.

~/AthanClock/RunAthan.sh enable-startup && ~/AthanClock/RunAthan.sh start

Change location

Answer the questions in the terminal, or pick a new city above and run the new install command.

~/AthanClock/RunAthan.sh configure

Check that it's running

Shows the status and the recent log.

~/AthanClock/RunAthan.sh status; ~/AthanClock/RunAthan.sh logs

Uninstall

Removes the background service and deletes the app folder.

~/AthanClock/RunAthan.sh uninstall && rm -rf ~/AthanClock

Questions

I don't hear anything

Make sure the right speaker (HDMI or headphone jack) is selected in the volume menu on your desktop, then run ~/AthanClock/RunAthan.sh restart. You should hear the chime. The log (~/AthanClock/RunAthan.sh logs) says Startup sound played OK when sound works.

Can I hear the Athan for Fajr too?

Yes. Open ~/AthanClock/prayer_clock.py, remove the # in front of the "Fajr" line, save, and run ~/AthanClock/RunAthan.sh restart.

Which calculation method should I choose?

The method suggested for your country is picked automatically. If your local mosque uses a different one, choose that instead. The times shown in step 1 update as you change it, so you can compare them with your mosque's timetable.

Is it safe to run a command from a website?

The command downloads install.sh from the project's GitHub and runs it. You can read that script first. It only installs python3, python3-requests and mpg123, and sets up the app under your user.
